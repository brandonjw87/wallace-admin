# wallace-admin

WALLACE Admin - Windows network health / admin dashboard (WPF, .NET 8). Installer: see Releases.

## Build
Open `src\` in Visual Studio / `dotnet publish -c Release -r win-x64`. Installer scripts: `installer-admin.iss` (Inno Setup).

GeoIP: download free GeoLite2-ASN.mmdb and GeoLite2-Country.mmdb from MaxMind (license required) into `src\`.

Free and open source (MIT).
